# Machine Learning from Scratch

从基础机器学习到 Transformer 与大语言模型，用手写代码理解模型背后的数学、架构和训练过程。

这个仓库记录我的学习与实现过程。目标不只是让代码运行起来，更是弄清楚：数据如何流经模型、参数如何更新，以及每个模块为什么这样设计。

## 学习目标

- 补齐机器学习、深度学习和 LLM 所需的基础知识。
- 从数学公式出发，用代码实现核心算法和模型。
- 理解 Transformer，并实现一个可以训练和生成文本的小型 GPT。
- 逐步学习语言模型的数据处理、预训练、微调、评估与推理。
- 在计算资源允许的范围内，从零训练自己的语言模型。

## 实现原则

- **核心模块自己写**：学习 Attention 时，不直接调用现成的 Attention 或 Transformer 层。
- **基础工具合理用**：使用 NumPy、PyTorch 的张量运算和自动求导，把精力放在理解模型上。
- **关注张量形状**：弄清楚每一步输入、输出及各维度的含义。
- **用实验验证理解**：检查梯度和参数更新，观察损失变化，验证 causal mask 是否阻止未来信息泄露。
- **先完成最小实现，再逐步扩展**：从单头 Attention 到完整模型，从一次参数更新到完整训练循环。

核心公式：

$$
\operatorname{Attention}(Q,K,V)
=
\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

不仅理解公式，也要能解释每一步的张量形状，以及梯度如何回传到参数。

## 学习路线

以下是逐步推进的计划，不代表仓库已经包含对应实现。

### 1. 机器学习基础

- 线性回归与逻辑回归
- 损失函数、梯度下降与正则化
- 数据集划分、过拟合与模型评估
- 决策树、K-Means、PCA 等经典算法

### 2. 深度学习基础

- 多层感知机与激活函数
- 反向传播与自动求导
- 参数初始化与优化器
- Batch、训练循环与模型保存
- 归一化、Dropout 与训练稳定性

### 3. Transformer

- Token Embedding 与位置编码
- Self-Attention 与 Multi-Head Attention
- Causal Mask 与 Padding Mask
- 前馈网络、残差连接与 LayerNorm
- Encoder、Decoder 与 Cross-Attention
- 原版 Transformer 与 GPT 架构的区别

### 4. 从零训练小型语言模型

- 从字符级建模开始，理解分词与词表
- 构造 next-token prediction 的输入与标签
- 实现小型 GPT
- 使用交叉熵训练模型
- 划分训练集与验证集，记录损失与生成样例
- 实现自回归生成、temperature 与 top-k / top-p 采样
- 保存和加载 checkpoint

先跑通完整流程，再根据数据质量、实验结果和计算资源扩展模型规模。

### 5. 补全 LLM 知识

- **架构**：RMSNorm、RoPE、SwiGLU、GQA
- **数据**：清洗、去重、分词与数据质量评估
- **训练**：学习率调度、混合精度、梯度累积与分布式训练基础
- **微调**：监督微调（SFT）、LoRA 与偏好优化基础
- **推理**：KV Cache、量化与推理效率
- **评估**：困惑度、任务表现与生成质量
